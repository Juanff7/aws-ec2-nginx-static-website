## Overview 

This project demonstrates how to deploy a static website on an AWS EC2 instance using Nginx

## Technologies Used

- AWS EC2
- AMAZON LINUX 2023
- NGINX
- SSH
- HTML
- CSS
- JavaScript

## Deployment Steps

1. Launch EC2 instance
2. Configure Security Group(SSH and http)
3. Connect using SSH
4. Install Nginx
5. Upload website files
6. Configure permissions
7. Access website via public IP
